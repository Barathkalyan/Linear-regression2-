# Linear-regression2
Machine learning with simple algorithms: One at a time!!
Linear Regression is a fundamental machine learning algorithm used to predict continuous target variables based on input features by finding the best-fit linear relationship. It minimizes the sum of squared differences between observed and predicted values.

This project utilizes the Wine Quality dataset to predict wine quality scores using Linear Regression. The dataset features include chemical properties of wines, and the target variable represents wine quality. The project involves data preprocessing, splitting data into training and testing sets, model training, prediction, and evaluation. Performance is assessed using Mean Squared Error (MSE) and R-squared (R²), ensuring effective and interpretable predictions.
